# इंडेक्स अंकगणित

आकार `[H, W]` पर `tensor[i, j]` एक्सेस `i * W + j` है। रेंज विभाजन, विलय, अनरोलिंग और GPU डाइमेंशन पुनर्निर्माण के बाद इंडेक्स एक्सप्रेशन में `FloorDiv`/`FloorMod` शृंखलाएँ जमा हो जाती हैं; बैकएंड तक बचा एक डिवीज़न दसियों साइकिल लेता है, जबकि बाकी पता एक साइकिल लेता है। यह पेज वह पूर्णांक बीजगणित है जो उन्हें हटाता है। स्रोत: `schedule/src/symbolic/patterns.rs` में `range_based_mod_div_patterns`, `advanced_division_dsl_patterns` और `div_mod_recombine_dsl_patterns`, `schedule/src/symbolic/divmod.rs` में `fold_divmod_general`, लोअरिंग `schedule/src/symbolic/index_lowering.rs` में। Tinygrad: `uop/divandmod.py`, `uop/symbolic.py`, `uop/weak.py`।

हर नियम के मूल में दो तथ्य हैं:

- इंडेक्स अंकगणित `WeakInt` रहता है जब तक चरण 17 उसे कमिट नहीं करता (`UOp::index_const` एक `WeakInt` बनाता है); `ScalarDType::Index` एक पुराना नाम है, और लोअरिंग के बाद `spec` सत्यापित करता है कि यह मौजूद नहीं है।
- हर रीराइट `exact_integer_rewrite` से गुज़रता है: उम्मीदवार तभी स्वीकार किया जाता है जब न मूल और न प्रतिस्थापन अपने ठोस dtype में wrap हो सकें। हेल्पर उम्मीदवारों को असीमित पूर्णांक बीजगणित में बनाते हैं; प्रमाण कॉल साइट पर होता है।

## रेंज-आधारित नियम (`range_based_mod_div_patterns`)

`SoundVminVmaxProperty` हर नोड का `[vmin, vmax]` देता है (`RANGE(end)` का `[0, end-1]` है):

| पैटर्न | परिणाम | शर्त |
|---------|--------|-------|
| `RANGE(end) % end`, `RANGE(end) // end` | रेंज, `0` | वही `end` नोड |
| `x % n` | `x` | `0 <= vmin(x)` और `vmax(x) < n` |
| `(a*n + b) % n` | `b % n` | `vmin(b) >= 0`; `n` की तुलना मान से |
| `(a*n + b + c) % n` | `(b + c) % n` | `vmin(b + c) >= 0` |
| `(a*n + b) // n` | `a` जब `0 <= b < n`, अन्यथा `a + b // n` | `n > 0`, `vmin(b) >= 0` |
| `x // n` | `k` | `vmin(x) // n == vmax(x) // n` (एक बकेट) |
| `(a + (x//n)*n) // n` | `x // n` | `0 <= a < n` |
| `(x + c) // d` | `x // d` | `c > 0`, `d > 0`, `vmin(x) >= 0`, और `x % d` का सबसे बड़ा संभव शेषफल जोड़ `c` अब भी `d` से कम |
| `(x + c) // d` | `(x + c%d) // d + c//d` | `c % d != c`, कोई भी `d != 0` |
| `(x + c) // d`, `x <= 0 <= x + c` | `-(-(c%d + x - (d-1)) // d) + c//d` | `d > 0` |

पहली दो पंक्तियाँ मुख्य काम करती हैं: विभाजन के बाद `RANGE(n) % n` और `(outer*4 + inner) // 4` ही पूरी कहानी हैं। `(x + c) // d` नियम में शेषफल की सीमा `x` की रेंज `[vmin, vmax]` पर गणना की जाती है, उसके स्ट्राइड पर नहीं, इसलिए `(R*4 + 1) // 8` तभी फ़ोल्ड होता है जब `R*4` 8 से कम मान फैलाए।

## उन्नत डिवीज़न (`advanced_division_dsl_patterns`)

| पैटर्न | परिणाम | शर्त |
|---------|--------|-------|
| `(a // b) // c` | `a // (b*c)` | `b != 0`, `c > 0`, `b*c` wrap नहीं होता |
| `expr // d` | `expr.divides(d)` | `expr` का हर योगात्मक पद पूर्णतः विभाज्य है (`UOp::divides` `Add` से होकर पुनरावर्ती चलता है, इसलिए दोनों विभाज्य होने पर `(a + b) // c` भी कवर है) |
| `(a + b) % c` | `b % c` या `a % c` | हटाया गया पद पूर्णतः विभाज्य है |
| `(x + c) % d` | `(x + c%d) % d` | `d > 0`, `c % d != c` |
| `x % y`, `x // y` | `fold_divmod_general(..)` | नीचे देखें |
| `(a - b) // c` | `a//c - b//c` | दोनों पूर्णतः विभाज्य |
| `(a//c1 + c2) // c3` | `(a + c1*c2) // (c1*c3)` | `c1, c3 > 0`, `a` और `c2` एक ही चिह्न के, गुणनफल wrap नहीं होते |

पूर्णांकों के लिए कोई सामान्य `c * (a + b)` वितरण नहीं है: सिर्फ़ पद-संयोजन और `sym_phase3_patterns` में `WeakInt` और `-1` रूप।

## `fold_divmod_general`

Tinygrad के `fold_divmod_general` का पोर्ट, जो किसी भी स्केलर पूर्णांक `FloorDiv`/`FloorMod` के लिए बुलाया जाता है जिसके हर की रेंज ठीक `{0}` न हो। नियम क्रम से; जो पहला उम्मीदवार देता है वह जीतता है:

1. **cancel** — यदि भागफल `x // y` की रेंज एकल-मान है, तो उसे लौटाएँ (`%` के लिए: `x - q*y`)।
2. **multiple-of guard** — ऐसे भाजक का `multiple_of` घोषित `PARAM` जो उसे विभाजित करता है: `% → 0`, `//` अछूता।
3. **nested_div** (सिर्फ़ `//`) — `(a % (k*c)) // c` → `(a // c) % k`, `k.vmin > 0`।
4. **remove_nested_mod** (सिर्फ़ `%`) — `(a % (k*c) + b) % c` → `(a + b) % c`।
5. **congruence** (`fold_divmod_congruence`) — `x = Σ f_i t_i + k` लिखें; हर गुणांक के लिए एक अवशेष `r_i ≡ f_i (mod c)` चुनें (दोनों चिह्नों में से छोटा; अकेले पद या पूर्ण बराबरी पर दोनों आज़माए जाते हैं, `itertools.product` क्रम में); यदि `rem = Σ r_i t_i + k%c` एक ही भागफल बकेट में रहता है, तो `x % c = rem - bucket*c` और `x // c = Σ (f_i - r_i)/c · t_i + (k - k%c + bucket*c)/c`। चिह्न-निरपेक्ष।
6. **gcd_with_remainder** — `g = gcd(c, all f_i) > 1` और ऋणेतर `x/g` के साथ: `((x/g + shift) // (c/g))` या `((x/g + shift) % (c/g)) * g + k%g`।
7. **nest_by_factor** — हर गुणांक `f` के लिए जो `c` को उचित रूप से विभाजित करता है (`2 <= f < c`), `x // c` को `(x // f) // (c/f)` के रूप में (भीतरी डिवीज़न को पुनरावर्ती फ़ोल्ड करते हुए) और `%` को `((x // f) % (c/f)) * f + x % f` के रूप में फिर से लिखें; सबसे छोटे `node_count()` वाला उम्मीदवार जीतता है। `%` शाखा को `x >= 0` और ऐसा निचला अंक चाहिए जो सिद्ध रूप से `[0, f)` में हो।
8. **divide_by_gcd** (कोई भी हर) — `x op y` → `(x/g) op (y/g)` (`%` के लिए `g` से गुणा) जब `symbolic_gcd(terms, y)` 1 न हो। यही सिम्बॉलिक `N` के लिए `(N*i + j) // N` को फ़ोल्ड करता है।
9. **factor_remainder** (कोई भी हर) — पदों को `y` से पूर्णतः विभाज्य पदों और बाकी में बाँटें; `//` → `quotient + rest // y`, `%` → `rest % y`; स्थिर भाजक गुणांक को उसके अवशेष तक भी घटाता है (`(r*8 + v) % 7` → `(r + v) % 7`)। इसके लिए `x >= 0`, `y >= 0` और ऋणेतर शेषफल चाहिए।

उदाहरण: `R: [0, 16)`, `v: [0, 8)` के साथ `(R*8 + v) // 8` — नियम 1 विफल (16 बकेट), नियम 5 गुणांक `8` के लिए अवशेष `0` और `v` के लिए `1` देता है, `rem = v ∈ [0, 7]` एक बकेट है, इसलिए भागफल `R` और शेषफल `v` है।

## पुनर्संयोजन

`fold_add_divmod_recombine`, हर `Add` पर (tier 1): एक स्केल किया हुआ शेषफल `(base % div) * mul` और साथी `q * (div*mul)` ढूँढता है, जहाँ `q` किसी ऐसी चीज़ का भागफल है जो `div` मॉड्यूलो `base` के सर्वांगसम है, और `b * mul` तथा बाकी पद लौटाता है — या `(b % (div*d)) * mul` जब `q` स्वयं `(b // div) % d` हो। वैरिएंट `x%n + (x//n)*n → x`, `(x//a)%c + (x//(a*c))*c → x//a`, `(x%c1)*c2 + (x//c1)*(c1*c2) → x*c2` और ऑफ़सेट रूप सभी इसी एक सर्च से निकलते हैं।

## इंडेक्स dtype लोअरिंग

`pm_lower_index_dtype` (चरण `17-pm_lower_index_dtype`, [devectorizer पेज](../codegen/devectorizer.md)) `WeakInt` को `Int32` या `Int64` पर कमिट करता है:

- `select_dtype(u)`: `WeakFloat` → डिफ़ॉल्ट float; `[i32::MIN, i32::MAX]` के भीतर पूर्णांक सीमाएँ → डिफ़ॉल्ट int, अन्यथा `Int64`।
- पत्तियाँ (`CONST`, `VCONST`, स्केलर `PARAM` वेरिएबल) `concrete.cast(WeakInt)` बन जाती हैं; `Unary`, `Binary`, `WHERE`, `RANGE`, `STACK`, `SPECIAL` अपने स्रोतों के cast खोलते हैं और ठोस dtype पर फिर से बनाए जाते हैं (बाइनरी op के लिए `select_dtype(u)` और स्रोतों का `least_upper_dtype`); weak `INDEX` अपने बफ़र को cast करता है और अपने इंडेक्स कमिट करता है; जो उपभोक्ता weak नहीं है वह अपने किनारे पर पीछे का cast सोख लेता है (`lower_weak_srcs`, प्रति कर्नेल memoized)।
- `WHERE(valid, idx, Invalid)` अपना आकार बनाए रखता है; `Invalid` कभी cast नहीं होता। जो गेटेड इंडेक्स `Int64` निकला, उसे वापस `Int32` तक संकुचित किया जाता है जब बफ़र की एलिमेंट गिनती `i32` में समा जाए।

वैधता `WHERE` दो चरण बाद `pm_move_gates_from_index` (`late/gater.rs`) में LOAD/STORE `gate` बन जाता है; `INDEX` में स्वयं कोई gate फ़ील्ड नहीं है।

## वर्क्ड उदाहरण

आकार `[4, 8]` वाला `tensor[i, j]`, जिसे `R0 ∈ [0, 32)` द्वारा 32 एलिमेंट पर फ़्लैट रूप से इटरेट किया जाता है:

```text
row = R0 // 8, col = R0 % 8
addr = row * 8 + col = (R0 // 8) * 8 + (R0 % 8)
```

पुनर्संयोजन तुरंत `addr = R0` देता है। अब 4 से अनरोल करें: `pm_split_ranges` `R1 ∈ [0, 8)`, `R2 ∈ [0, 4)` के साथ `R0 = R1 * 4 + R2` प्रतिस्थापित करता है:

```text
row = (R1*4 + R2) // 8
col = (R1*4 + R2) % 8
```

इन पर `graph_rewrite(symbolic(), ..)` चलाने पर (नीचे के ट्री उसका आउटपुट हैं):

```text
row = (R1*4 + R2)//8
[31] FloorDiv : Scalar(WeakInt) shape=[]
├── [13] RANGE(R1, Weak) : Scalar(WeakInt) shape=[]
│   └── [2] CONST(Int(8)) : Scalar(WeakInt) shape=[]
└── [29] CONST(Int(2)) : Scalar(WeakInt) shape=[]

col = (R1*4 + R2)%8
[55] Add : Scalar(WeakInt) shape=[]
├── [54] Mul : Scalar(WeakInt) shape=[]
│   ├── [50] FloorMod : Scalar(WeakInt) shape=[]
│   │   ├── [13] RANGE(R1, Weak) : Scalar(WeakInt) shape=[]
│   │   │   └── [2] CONST(Int(8)) : Scalar(WeakInt) shape=[]
│   │   └── [46] CONST(Int(2)) : Scalar(WeakInt) shape=[]
│   └── [14] CONST(Int(4)) : Scalar(WeakInt) shape=[]
└── [15] RANGE(R2, Weak) : Scalar(WeakInt) shape=[]
    └── [14] → (see above)
```

`row`: नियम 1 विफल (चार बकेट), congruence विफल (`rem = R1*4 + R2 ∈ [0, 31]` चार बकेट में फैला है), `gcd(8, 4, 1) = 1`, और `f = 4` के साथ `nest_by_factor` congruence से `(R1*4 + R2) // 4` को `R1` में फ़ोल्ड करता है (`rem = R2 ∈ [0, 3]`) और `R1 // 2` छोड़ता है। `col`: वही गुणनखंड `(R1 % 2) * 4 + R2` देता है। फिर से जोड़ने पर `row*8 + col` पुनर्संयोजित होकर `R1*4 + R2` बनता है — पता फिर से रैखिक है, भले ही `row` और `col` अलग-अलग अब भी एक डिवीज़न और एक मॉड्यूलो रखते हों। एक बार और विभाजित करें, `R1 = R3 * 2 + R4` (`R3 ∈ [0, 4)`, `R4 ∈ [0, 2)`), और रेंज-आधारित नियम काम पूरा कर देते हैं:

```text
row = (R3*8 + R4*4 + R2) // 8   → R3                (a*n + b)//n with b = R4*4 + R2 ∈ [0, 7]
col = (R3*8 + R4*4 + R2) % 8    → R4*4 + R2         (a*n + b + c)%n, then x % n → x
addr = row*8 + col              → (R4*4 + R2) + R3*8
```

शून्य डिवीज़न, शून्य मॉड्यूलो: टाइल किया गया पता ही फ़्लैट पता है, रीराइटिंग द्वारा सिद्ध। उसी रन के दो और आउटपुट: `R: [0, 16)`, `v: [0, 8)` के साथ `(R*8 + v) // 8` → `R` (नियम 5), और `(R*8 + v) % 7` → `(R + v) % 7` (नियम 9 का गुणांक घटाव)।
